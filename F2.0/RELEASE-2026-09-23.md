## 還原與使用

ZIP 保存 F2.0 程式與執行素材、目前逐字稿及三支新版原始音檔，不包含 node_modules、dist、私人環境檔與機器專屬 Windows settings.json。
解壓後進入 F2.0，執行 npm install，再執行 npm start；Windows 可依「Windows展場安裝與操作.md」啟動。

瀏覽器中的個別版面校正、外框格線開關與螢幕選擇不會自動包含在程式 ZIP。要移轉現場瀏覽器的校正值，請於各介面 E 編輯器另行匯出 JSON。
