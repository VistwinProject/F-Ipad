# 三介面效能檢查（2026-09-23）

## 已調整

- 三介面的連續狀態事件合併至下一個畫面幀處理，保留所有事件種類；音訊停止與開場狀態仍立即處理，避免重置事件被合併後漏掉。
- iPad 設備摘要與 SVG 連線內容未變時，不再重建 DOM。
- Table 首頁遮住背景、頁面隱藏時，停止計算與寫入動態漸層；編輯器關閉時不再量測面板尺寸。
- Table 輪播在隱藏頁面或未開始體驗時不切換面板；離頁清除輪播、完成提示與待處理重畫。
- Table / iPad 無光線需要繪製時，清空畫面一次後略過空白 bloom 繪圖。
- AI 球體畫布依 CSS 大小和螢幕像素密度配置，最長邊上限 1024；保留 shader、狀態參數及動畫。頁面隱藏時略過 GPU 提交。

- stable-bloom.js、wall-core-glow.js 未被目前入口引用，保留在磁碟不代表背景執行，本次未刪除。

## 限制

尚未在實際展場電腦、投影機與實體 iPad 進行長時間 FPS、GPU 與記憶體量測；不能保證所有硬體完全無卡頓。球體畫布會隨顯示大小調整，超大尺寸的細節需於實機確認。

## 後續調整：恢復球體高解析度

依使用者要求，球體已恢復原本短邊 1600 像素的畫布（正方形為 1600×1600），取消依顯示大小縮減與 1024 上限。前述 888×888 與 69.2% 減量僅為當時優化版本的紀錄，不適用目前版本。其餘更新合併、DOM 重用及隱藏頁面略過 GPU 提交等優化保留。
